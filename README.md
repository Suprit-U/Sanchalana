# Sanchalana

![Status](https://img.shields.io/badge/Status-Active-success) ![License](https://img.shields.io/badge/License-MIT-blue)

A modern, responsive web application focused on state management and robust authentication flows. Built with a clean UI and scalable architecture.

## ?? Features
- Secure Authentication
- Real-time updates
- Responsive design
- Comprehensive dashboard

## ??? Tech Stack
- Frontend: React, TypeScript, Vite
- Styling: Tailwind CSS
- Backend: Supabase

## ?? Setup & Installation
1. Clone the repository
2. Run 
pm install
3. Copy .env.example to .env and fill in your keys
4. Run 
pm run dev

## ?? Folder Structure
- src/: Source code
- public/: Static assets
